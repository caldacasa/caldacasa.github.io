Conectează statisticile

Ai nevoie o singură dată de cheia API din GoatCounter. Cheia rămâne doar în acest browser.

  1. Deschide caldacasa.goatcounter.com → Settings → API.
  2. Creează o cheie nouă și bifează doar Read statistics.
  3. Copiaz-o și lipește-o mai jos.
